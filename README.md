# USERAGENT

Расширение Chrome/Edge (Manifest V3) для переключения User-Agent и связанных с ним Client Hints.

**Версия:** 1.0.2

## Структура проекта

```text
USERAGENT/
├── manifest.json
├── background/
│   ├── service-worker.js       Точка входа фонового процесса
│   ├── config.js               Настройки, профили UA, область действия
│   ├── core.js                 Применение профилей и обработка сообщений
│   ├── chrome.js               Вызовы Chrome Extension API
│   ├── netrequest.js           Управление правилами declarativeNetRequest
│   ├── runtime.js              События установки и подключения
│   ├── ua/
│   │   ├── hints.js            Client Hints и метаданные
│   │   ├── rules.js            Правила изменения заголовков
│   │   └── legacy.js           Совместимость со старыми конфигурациями
│   └── tabs/
│       ├── pertab.js           Профили отдельных вкладок
│       └── watcher.js          Состояние вкладок и значок
├── content/
│   ├── isolated.js             Скрипт в изолированном окружении
│   └── main.js                 Скрипт в окружении страницы
├── popup/
│   ├── popup.html              Интерфейс
│   ├── popup.css
│   ├── popup.js                Обработка интерфейса
│   ├── i18n.js                 Загрузка и применение переводов
│   ├── sections/               Разделы настроек и стили
│   ├── explore/                Дополнительный интерфейс
│   └── icons/                  Значки профилей в popup
├── assets/icons/               Значки расширения и панели
├── _locales/
│   ├── en/messages.json        Английский
│   └── ru/messages.json        Русский
└── tests/                      Автоматические и браузерные проверки
```

Функциональная группировка удобнее плоского каталога для проекта с несколькими независимыми механизмами. `service-worker.js` использует синхронные `importScripts` классического воркера; каждый путь разрешается относительно `background/`. Файлы, внедряемые через `chrome.scripting`, указываются относительно корня расширения.

## Язык интерфейса

В разделе **Settings / Настройки → Interface language / Язык интерфейса** доступны:

- **Browser language / Язык браузера** — выбор по языку интерфейса Chrome/Edge;
- **Русский**;
- **English**.

Переключение языка интерфейса не изменяет выбранный User-Agent, заголовок `Accept-Language` и настройку **Match browser language**. Выбор сохраняется в `chrome.storage.local` как `useragent-ui-language`.

Локализация манифеста использует `__MSG_...__`; подписи, подсказки и сообщения интерфейса — ключи из `_locales/en/messages.json` и `_locales/ru/messages.json`.

## Установка

1. Открыть `chrome://extensions/` или `edge://extensions/`.
2. Включить режим разработчика.
3. Выбрать **Загрузить распакованное расширение** и указать каталог `C:\FILES\PROJECTS\USERAGENT`.
4. При обновлении исходников нажать **Обновить**, затем открыть popup заново.

## Проверка

Требуется Node.js без сторонних зависимостей:

```powershell
cd C:\FILES\PROJECTS\USERAGENT
node --test .\tests\*.test.js
```

Для проверки синтаксиса всех скриптов:

```powershell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

## Версионирование

`manifest.json` — единственный источник номера релиза. Каждый завершённый этап, передаваемый как новая версия, увеличивает **PATCH** на единицу: `1.0.2 → 1.0.3 → 1.0.4`. Мелкие промежуточные сохранения в рамках одного релиза версию не повышают.

Правила совместимости: значения сохранённых настроек и их ключи должны оставаться действительными между версиями. При обновлении интерфейса добавляются переводы в оба языковых каталога; тесты проверяют полноту ключей.

## Ограничения

Подмена User-Agent и Client Hints не означает блокировку cookies, IP-адреса, Canvas, WebGL и других каналов определения устройства. Исходный режим совместимости `Native disguising` остаётся доступным.
